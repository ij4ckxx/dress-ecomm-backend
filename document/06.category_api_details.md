# Category & Product Discovery API Documentation (Customer-Facing)

This documentation provides frontend developers with a complete, practical guide to integrating the customer-side **Category Hierarchy** and **Product Discovery** APIs.

---

## 1. Base URL & Common Headers

- **Localhost**: `http://localhost:5000/api/v1` *(also supports `/api`)*
- **Production (Render)**: `https://dress-ecomm-backend.onrender.com/api/v1` *(also supports `/api`)*

### Headers
```http
Content-Type: application/json
```

### Authentication Behavior (Guest-Friendly)
- **Public Catalog**: All category and product APIs are publicly accessible. Guests **do not** need to log in to browse, search, filter, or view details.
- **Optional Authorization**: If the customer is logged in, include the header:
  ```http
  Authorization: Bearer <accessToken>
  ```
  When provided, the backend automatically personalizes the response by setting `isWishlisted: true` or `isWishlisted: false`. If no token is provided, `isWishlisted` safely defaults to `false` without throwing 401 errors.

## 2. Quick Summary of Endpoints

| Method | Endpoint | Description | Auth Required |
| :--- | :--- | :--- | :--- |
| `GET` | `/categories` | List categories (nested tree, root-only, or flat) | Optional |
| `GET` | `/categories/:slug` | Get single category with breadcrumb hierarchy & children | Optional |
| `GET` | `/categories/:slug/products` | Category Product Listing Page (PLP) with lightweight cards | Optional |
| `GET` | `/products` | Reusable Product Discovery (search, filter, dynamic attributes, sort, pagination) | Optional |
| `GET` | `/products/:slug` | Complete Product Details Page (PDP) with gallery, variants & modifiers | Optional |

## 3. Core Concepts for the Frontend Team

### A. The 3-Tier Pricing Model
Every product and variant returns a structured `price` object:
```json
{
  "regular": 12500,
  "sale": 9999,
  "offer": 8499,
  "effective": 8499,
  "discountPercentage": 32
}
```

#### How the Frontend Should Display Prices:
1. **Current Display Price**: Always display `price.effective`.
2. **Discount Badge**: If `price.discountPercentage > 0`, render a discount badge (e.g., `-32% OFF`).
3. **Strikethrough Price**: If `price.regular > price.effective`, render `price.regular` with a strikethrough (e.g., `<s>₹12,500</s>`).
4. **Special Offer Highlight**: If `price.offer !== null`, you can highlight it as a "Special Limited Deal".

---

### B. Add-to-Cart Readiness (`requiresConfiguration`)
On category pages or search listings, you can determine what action button to show on each product card:

```typescript
if (product.requiresConfiguration) {
  // Show "Choose Options" button -> navigates to /products/[slug]
  renderButton("Choose Options", () => router.push(`/products/${product.slug}`));
} else {
  // Show "Add to Cart" button -> simple item, can be directly added!
  renderButton("Add to Cart", () => addToCart(product.id));
}
```

- `requiresConfiguration: false`: Product has no variant choices or required modifiers.
- `requiresConfiguration: true`: Product requires selecting a Size/Color variant or modifier option.

---

### C. Standardized Pagination Structure
All paginated endpoints return metadata in this standard format:

```json
"pagination": {
  "page": 1,
  "limit": 24,
  "total": 45,
  "totalPages": 2,
  "hasNextPage": true,
  "hasPreviousPage": false
}
```

Use `hasNextPage` and `page` to drive traditional pagination buttons or infinite scrolling.

---

### D. Supported Sort Options
Pass the `sort` query parameter using one of these whitelisted keys:

| Sort Value | Description | Best Used For |
| :--- | :--- | :--- |
| `bestselling` | Highest total sold units first | "Best Sellers" filter tab |
| `best_deals` | Highest discount percentage first | "Sale & Offers" tab |
| `newest` | Newly created products first (Default) | "New Arrivals" tab |
| `oldest` | Oldest products first | Catalog archives |
| `price_asc` | Lowest price to highest price | "Price: Low to High" |
| `price_desc` | Highest price to lowest price | "Price: High to Low" |
| `rating` | Highest customer rating first | "Top Rated" |
| `name_asc` | Alphabetical A to Z | Alphabetical sorting |
| `name_desc` | Alphabetical Z to A | Reverse alphabetical |

---

### E. Dynamic Attribute Filtering
Filter by any dynamic attribute created in the store by passing the attribute slug and value slug in the query string:
- `?color=emerald-green`
- `?size=m`
- `?fabric=mulberry-silk`
- `?occasion=evening`

Multiple filters can be combined:
```http
GET /products?category=womens-couture&color=emerald-green&fabric=mulberry-silk&minPrice=5000&maxPrice=15000&sort=best_deals
```

Fetch categories for navigation bars, mega-menus, sidebars, or homepage carousels.

- **Method**: `GET`
- **URL**: `/categories`

| `rootOnly` | `boolean` | No | `false` | When `true`, returns only top-level root categories (`parentId: null`). Ideal for top nav tabs. |

```http
GET /api/v1/categories?tree=true
```

### 4) Reusable Product Discovery API
The main catalog endpoint for search, faceted filtering, dynamic attributes, sorting, and pagination.

- **Method**: `GET`
- **URL**: `/products`
- **Auth**: Optional (Pass `Authorization: Bearer <token>` for personalized `isWishlisted`)

#### Query Parameters
| Parameter | Type | Required? | Default | Example | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `page` | `number` | No | `1` | `1` | Page number |
| `limit` | `number` | No | `24` | `24` | Items per page (max 100) |
| `search` | `string` | No | - | `gown` | Searches name, description, brand, SKU & category |
| `category` | `string` | No | - | `mens-shirts` | Category slug or ID (includes subcategories) |
| `brand` | `string` | No | - | `Savile & Co` | Filter by brand name (case-insensitive) |
| `minPrice` | `number` | No | - | `2000` | Minimum regular price |
| `maxPrice` | `number` | No | - | `10000` | Maximum regular price |
| `sort` | `string` | No | `newest` | `bestselling` | Sort key (see Section 3.D) |
| `isFeatured` | `boolean` | No | - | `true` | Filter curated featured products |
| `[attribute]` | `string` | No | - | `color=emerald-green` | Dynamic attribute filters (e.g. `fabric=organic-linen`) |

### 5) Product Details Page (PDP)
Returns everything needed to render a rich, interactive product detail page:
- High-res image gallery with thumbnails
- Dynamic product attributes (Fabric, Occasion, Material, etc.)
- Combinatorial variants with independent SKUs, stock levels, and variant-specific pricing
- Modifier options with pricing adjustments (e.g., Gift Wrap, Custom Stitching)
- Real-time stock status (`inStock: true/false`)
- Wishlist status

- **Method**: `GET`
- **URL**: `/products/:slug`
- **Auth**: Optional (Pass `Authorization: Bearer <token>` for personalized `isWishlisted`)

| `slug` | `string` | **Yes** | `elysian-emerald-silk-evening-gown` | Product URL slug |

## 5. Frontend Integration Examples (React / Next.js)

### A. API Client Service (`services/catalogApi.ts`)
```typescript
const BASE_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:5000/api/v1';

// Helper to attach token if user is logged in
const getHeaders = () => {
  const token = typeof window !== 'undefined' ? localStorage.getItem('accessToken') : null;
  return {
    'Content-Type': 'application/json',
    ...(token ? { Authorization: `Bearer ${token}` } : {}),
  };
};

// 1. Fetch Category Tree for Mega Menu
export const fetchCategoryTree = async () => {
  const res = await fetch(`${BASE_URL}/categories?tree=true`, {
    headers: getHeaders(),
  });
  const data = await res.json();
  if (!res.ok) throw new Error(data.message);
  return data.data;
};

// 2. Fetch Filtered Products with Pagination
export const fetchProducts = async (params: Record<string, any> = {}) => {
  const query = new URLSearchParams();
  Object.entries(params).forEach(([key, value]) => {
    if (value !== undefined && value !== null && value !== '') {
      query.append(key, String(value));
    }
  });

  const res = await fetch(`${BASE_URL}/products?${query.toString()}`, {
    headers: getHeaders(),
  });
  const data = await res.json();
  if (!res.ok) throw new Error(data.message);
  return {
    products: data.data,
    pagination: data.pagination,
  };
};

// 3. Fetch Product Details
export const fetchProductBySlug = async (slug: string) => {
  const res = await fetch(`${BASE_URL}/products/${slug}`, {
    headers: getHeaders(),
  });
  const data = await res.json();
  if (!res.ok) throw new Error(data.message);
  return data.data;
};
```

### B. Selecting Variants & Updating PDP Price in React
```tsx
import React, { useState } from 'react';

export function ProductDetails({ product }: { product: any }) {
  const [selectedSize, setSelectedSize] = useState<string>('M');
  const [selectedColor, setSelectedColor] = useState<string>('emerald-green');

  // Find active variant matching selected attributes
  const activeVariant = product.variants.find((v: any) =>
    v.attributes.some((a: any) => a.attributeSlug === 'size' && a.valueSlug === selectedSize.toLowerCase()) &&
    v.attributes.some((a: any) => a.attributeSlug === 'color' && a.valueSlug === selectedColor.toLowerCase())
  );

  // Fallback to base product price if no specific variant price exists
  const currentPrice = activeVariant?.price || product.price;

  return (
    <div className="product-page">
      <h1>{product.name}</h1>

      {/* Pricing Display */}
      <div className="pricing-box">
        <span className="effective-price">₹{currentPrice.effective.toLocaleString()}</span>
        {currentPrice.discountPercentage > 0 && (
          <>
            <span className="regular-price"><s>₹{currentPrice.regular.toLocaleString()}</s></span>
            <span className="badge">-{currentPrice.discountPercentage}% OFF</span>
          </>
        )}
      </div>

      {/* Stock Status */}
      <p className={activeVariant?.inStock ? 'in-stock' : 'out-of-stock'}>
        {activeVariant?.inStock ? `In Stock (${activeVariant.stockQuantity} available)` : 'Sold Out'}
      </p>

      {/* Add To Cart */}
      <button disabled={!activeVariant?.inStock}>
        {activeVariant?.inStock ? 'Add to Cart' : 'Out of Stock'}
      </button>
    </div>
  );
}
```
