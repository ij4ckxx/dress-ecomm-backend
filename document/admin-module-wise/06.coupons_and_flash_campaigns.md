# Module 06: Coupons, Discounts & Flash Campaigns API

> **Module:** 06 - Coupons, Discounts & Flash Campaigns  
> **Audience:** Frontend Development Team (`/admin/discounts`, `/admin/promotions`)  
> **Base URLs:**  
> - Coupons: `/api/v1/admin/coupons` (or alias `/api/v1/admin/discounts`)  
> - Flash Campaigns: `/api/v1/admin/promotions`  
> **Auth Required:** `Authorization: Bearer <accessToken>`  
> **Required Permissions:**  
> - Coupons: `coupons:manage`  
> - Flash Campaigns: `promotions:manage`  
> *(Automatic root bypass for `SUPER_ADMIN`)*  

---

## 1. Overview & Architecture

This engine powers marketing discount strategies, promotional banner carousels, and seasonal festival sales for the luxury storefront:

1. **Coupon Rules & Limits:**
   - **Discount Types:** `PERCENTAGE` (1% to 100%) or `FIXED` (e.g., ₹1,000 off).
   - **Min Order Basket:** `minOrderAmount` prevents margin erosion on smaller purchases.
   - **Cap Protection:** `maxDiscountAmount` caps maximum deductions on high-ticket couture items (e.g., 25% off up to max ₹3,000).
   - **Usage Quotas:** Global `usageLimit` + `perUserLimit` (e.g. 1 redemption per customer).
   - **Date Bounds:** Enforces strict `startDate` and `endDate`.
2. **Safe Deactivation vs Hard Deletes:**
   - If a coupon has already been used in historical orders, calling `DELETE` automatically **soft-deactivates** (`isActive: false`) to preserve order invoices and ledger history.
3. **Hero Banners & Flash Campaigns:**
   - Manages marketing banners (`title`, `subtitle`, `badge`, `couponCode`, `ctaText`, `ctaLink`).
   - Supports in-memory direct upload to **Cloudinary** (`multipart/form-data`) or remote URLs.

## 2. Coupons & Discounts Endpoints

### 2.1. List Coupons
Retrieves paginated coupons with real-time status and remaining quota metrics.

- **Endpoint:** `GET /api/v1/admin/coupons`
- **Headers:** `Authorization: Bearer <token>`
- **Query Parameters:**
  - `page`: Page number (Default: `1`)
  - `limit`: Items per page (Default: `20`, Max: `100`)
  - `search`: Searches across code and description
  - `status`: `"ALL"` (default), `"ACTIVE"`, `"EXPIRED"`, `"INACTIVE"`
  - `discountType`: `"ALL"`, `"PERCENTAGE"`, `"FIXED"`
  - `sort`: `"newest"` (default), `"oldest"`, `"code_asc"`, `"used_desc"`
- **Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Coupons fetched successfully",
  "data": [
    {
      "id": "coup_uuid_101",
      "code": "DIWALI25",
      "description": "Exclusive 25% off festive preview collection",

      "discountValue": "25.00",
      "minOrderAmount": "5000.00",
      "maxDiscountAmount": "3000.00",
      "startDate": "2026-10-15T00:00:00.000Z",
      "endDate": "2026-11-05T23:59:59.000Z",
      "usageLimit": 500,
      "usedCount": 82,
```

### 2.3. Create Coupon
- **Endpoint:** `POST /api/v1/admin/coupons`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: application/json`
- **Request Body:**
```json
{
  "code": "FESTIVE20",
  "description": "Autumn gala launch coupon",
  "discountType": "PERCENTAGE",
  "discountValue": 20,
  "minOrderAmount": 4000,
  "maxDiscountAmount": 2000,
  "startDate": "2026-10-15T00:00:00Z",
  "endDate": "2026-10-31T23:59:59Z",
  "usageLimit": 200,
  "perUserLimit": 1,
  "isActive": true
}
```
- **Response `201 Created`:**
```json
{
  "success": true,
  "statusCode": 201,
  "message": "Coupon 'FESTIVE20' created successfully",
  "data": {
    "id": "coup_uuid_102",
    "code": "FESTIVE20",
    "discountType": "PERCENTAGE",
    "discountValue": "20.00",
    "usageLimit": 200,
    "usedCount": 0,
    "isActive": true
  }
}
```

---

### 2.4. Update Coupon
- **Endpoint:** `PUT /api/v1/admin/coupons/:id`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: application/json`
- **Request Body:** `{ "usageLimit": 300, "endDate": "2026-11-10T23:59:59Z" }`
- **Response `200 OK`**

---

### 2.5. Toggle Coupon Status
- **Endpoint:** `PATCH /api/v1/admin/coupons/:id/status`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: application/json`
- **Request Body:** `{ "isActive": false }`
- **Response `200 OK`**

---

### 2.6. Delete / Deactivate Coupon
- **Endpoint:** `DELETE /api/v1/admin/coupons/:id`
- **Headers:** `Authorization: Bearer <token>`
- **Response `200 OK`:**
  - If used: `{ "success": true, "message": "Coupon has 82 historical order usages. It was deactivated instead of permanently deleted to safeguard invoice history." }`
  - If unused: `{ "success": true, "message": "Coupon 'FESTIVE20' successfully deleted" }`

### 3.2. Create Promotional Campaign (With Image Upload)
- **Endpoint:** `POST /api/v1/admin/promotions`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: multipart/form-data`
- **Form Data Fields:**
  - `title`: String (required)
  - `subtitle`: String (optional)
  - `badge`: String (e.g. "SPECIAL PROMO")
  - `discountPercentage`: Number (e.g. 25)
  - `couponCode`: String (e.g. "DIWALI25")
  - `startDate`: ISO datetime
  - `endDate`: ISO datetime
  - `ctaText`: String ("SHOP THE SALE")
  - `ctaLink`: String ("/products")
  - `sortOrder`: Number (0)
  - `backgroundImage`: Optional file or URL string (uploaded directly to Cloudinary)
- **Response `201 Created`**

---

### 3.3. Update Promotional Campaign
- **Endpoint:** `PUT /api/v1/admin/promotions/:id`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: multipart/form-data` or `application/json`
- **Response `200 OK`**

---

### 3.4. Toggle Campaign Status
- **Endpoint:** `PATCH /api/v1/admin/promotions/:id/status`
- **Request Body:** `{ "isActive": false }`
- **Response `200 OK`**

---

### 3.5. Delete Promotional Campaign
- **Endpoint:** `DELETE /api/v1/admin/promotions/:id`
- **Response `200 OK`**
