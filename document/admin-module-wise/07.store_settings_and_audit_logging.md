# Module 07: Store Settings, Feature Flags & Audit Logging API

> **Module:** 07 - Store Settings, Feature Flags & Audit Logging  
> **Audience:** Frontend Development Team (`/admin/settings`, `/admin/audit-logs`)  
> **Base URLs:**  
> - Store Settings: `/api/v1/admin/settings`  
> - Audit Logs: `/api/v1/admin/audit-logs`  
> **Auth Required:** `Authorization: Bearer <accessToken>`  
> **Required Permission:** `settings:manage` (`SUPER_ADMIN` only)  

---

## 1. Overview & Architecture

This module governs global store preferences, instant storefront feature flag toggling, active theme switching, and immutable security audit logs:

1. **Store Identity & Shipping Rules:**
   - Store branding: `storeName`, `tagline`, `currency`, `currencySymbol`, `supportEmail`, `supportPhone`.
   - Shipping thresholds: `freeShippingThreshold` (e.g. ₹2,999) and `flatShippingRate` (e.g. ₹150).
2. **Instant Feature Flags Engine:**
   - Dynamically turn luxury storefront modules on or off without redeploying frontend or backend code:
     - `guestCheckout` (Allow purchasing without mandatory login)
     - `cashOnDelivery` (Enable/disable COD payments)
     - `onlinePayment` (Enable/disable Razorpay/Stripe checkout)
     - `wishlist` (Heart saving feature)
     - `reviews` (Customer ratings & garment reviews)
     - `coupons` (Discount code input at checkout)
     - `productVariants` (Sizing swatches & multi-color selector)
     - `whatsapp` (Floating VIP styling concierge widget)
     - `newsletter` (VIP newsletter signup popups)
     - `recommendations` (AI / similar dresses carousel)
     - `sizeChart` (Garment measurement guide modal)
     - `orderTracking` (Live courier status tracking bar)
3. **Multi-Theme Preset Switcher:**
   - Allows switching storefront design themes in real-time (`luxury-fashion`, `monochrome-minimal`, `royal-festive`).
4. **Immutable Audit Logging (`AuditLog`):**
   - Automatically tracks every administrative action across products, inventory adjustments, orders, coupons, and settings with:
     - Staff attribution (`userId`, `name`, `email`)
     - Action verb (`CREATE_PRODUCT`, `UPDATE_SETTINGS`, `CANCEL_ORDER`, `ADJUST_STOCK`, etc.)
     - Entity target and ID
     - IP address and User-Agent capture
     - Detailed JSON diff / metadata payload

### 2.2. Update General Store Settings
Updates contact information, store name, or shipping thresholds.

- **Endpoint:** `PUT /api/v1/admin/settings`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: application/json`
- **Request Body:**
```json
{
  "storeName": "Maison De Élégance",
```

### 2.3. Switch Storefront Theme
Switches the design system theme preset for the Next.js buyer storefront.

- **Endpoint:** `PATCH /api/v1/admin/settings/theme`
- **Headers:** `Authorization: Bearer <token>`, `Content-Type: application/json`
- **Request Body:**
```json
{
  "themeId": "royal-festive"
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Active storefront theme switched to 'royal-festive'",
  "data": {
    "activeTheme": "royal-festive"
  }
}
```

## 3. Administrative Audit Logs Endpoints

### 3.1. List Audit Logs
Retrieves paginated administrative audit logs with filtering by action, staff user, entity, or search.

- **Endpoint:** `GET /api/v1/admin/audit-logs`
- **Headers:** `Authorization: Bearer <token>`
- **Query Parameters:**
  - `page`: Page number (Default: `1`)
  - `limit`: Items per page (Default: `20`, Max: `100`)
  - `action`: Filter by action verb (e.g. `UPDATE_FEATURE_FLAGS`, `CANCEL_ORDER`, `ADJUST_STOCK`)
  - `entity`: Filter by entity type (e.g. `STORE_CONFIG`, `ORDER`, `PRODUCT`, `COUPON`)
  - `userId`: Filter by staff user UUID
  - `startDate`: ISO datetime start
  - `endDate`: ISO datetime end
  - `search`: Searches across action, entity, entity ID, and staff user name/email
- **Response `200 OK`:**
```json

  "message": "Audit logs fetched successfully",
```

## 4. Frontend UI Implementation Guidelines

### 4.1. Feature Flag Switches
- Render a toggle grid card with icons:
  - 🛍️ **Guest Checkout:** Toggle `guestCheckout`
  - 💵 **Cash on Delivery:** Toggle `cashOnDelivery`
  - 💳 **Online Payment:** Toggle `onlinePayment`
  - 💖 **Wishlist:** Toggle `wishlist`
  - 💬 **WhatsApp Concierge:** Toggle `whatsapp`
  - 📏 **Size Measurement Chart:** Toggle `sizeChart`
- On toggle change, send `PATCH /api/v1/admin/settings/features` with the toggled key.

### 4.2. Theme Switcher Cards
Render visual cards for each theme option with color swatches:
- **`luxury-fashion`** (Default): Noir Black, Gold foil accent, Silk White.
- **`monochrome-minimal`**: Slate Gray, Clean White, Architectural font.
- **`royal-festive`**: Deep Crimson, Embroidered Gold, Regal Ivory.
- Highlight the active card based on `activeTheme`.
- Clicking "Apply Theme" triggers `PATCH /api/v1/admin/settings/theme`.

### 4.3. Audit Log Timeline Table
- Display formatted action badges:
  - Green (`bg-emerald-50 text-emerald-700`): `CREATE_*`
  - Blue (`bg-blue-50 text-blue-700`): `UPDATE_*`
  - Red (`bg-rose-50 text-rose-700`): `DELETE_*`, `CANCEL_*`
  - Amber (`bg-amber-50 text-amber-700`): `ADJUST_*`
- Provide expandable row to inspect formatted JSON in `detailsJson`.
