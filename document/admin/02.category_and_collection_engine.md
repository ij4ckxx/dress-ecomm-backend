# Module 02: Category & Curated Collection Engine API

> **Module:** 02 - Category & Curated Collection Engine  
> **Audience:** Frontend Development Team (`/admin/categories`, `/admin/collections`)  
> **Base URLs:**  
> - Categories: `/api/v1/admin/categories`  
> - Collections: `/api/v1/admin/collections`  
> **Auth Required:** `Authorization: Bearer <accessToken>`  
> **Required Permissions:** `categories:manage` / `collections:manage` (Automatic for `SUPER_ADMIN`)  

---

## 1. Overview & Architecture

This module powers store taxonomy and marketing lookbooks:

1. **Category Hierarchy Engine:**
   - Supports arbitrary nesting: Root categories $\rightarrow$ Subcategories $\rightarrow$ Deep sub-levels.
   - Built-in **Circular Hierarchy Guard**: You cannot select a category or any of its own descendants as its parent.
   - Built-in **Collision-Safe Slugs**: Auto-generates clean URLs (e.g. `"Banarasi Silk"` $\rightarrow$ `banarasi-silk`) and automatically appends `-1`, `-2` if duplicates exist.
   - Safe Deletion: Prevents deleting categories that still have active products or subcategories attached unless `?force=true` is explicitly requested.
2. **Curated Collection Engine:**
   - Seasonal lookbooks and capsule edits (e.g. *"Royal Festive Edit 2026"*, *"Monsoon Linen Capsule"*).
   - Custom Product Ordering: Reorder and sequence garments within each collection (`sortOrder`).
   - One-click bulk product syncing (`PUT /products` with an array of product IDs).
3. **Image Upload Flexibility:**
   - You can send a regular JSON string (`"imageUrl": "https://..."`) **OR** upload an actual image file via `multipart/form-data` with key `image`. Images stream directly to Cloudinary with zero local disk storage.

## 2. Category API Specifications

### 2.1. List Categories
Retrieves categories in nested tree, flat table, or root-only mode.

- **Endpoint:** `GET /api/v1/admin/categories`
- **Headers:** `Authorization: Bearer <token>`
- **Query Parameters:**
  - `view`: `"tree"` (Default - nested tree), `"flat"` (paginated table), `"root"` (top-level only)
  - `search`: Search query string
  - `isActive`: `"true"` or `"false"`
  - `isFeatured`: `"true"` or `"false"`
  - `parentId`: Filter by direct parent UUID (in flat view)
  - `page`: Page number (for flat view, default `1`)
  - `limit`: Items per page (for flat view, default `50`)
- **Example Request:**
  `GET /api/v1/admin/categories?view=tree`
- **Response `200 OK` (Tree View):**

### 2.3. Create Category
Creates a new root or nested category.

- **Endpoint:** `POST /api/v1/admin/categories`
- **Headers:**
  - `Authorization: Bearer <token>`
  - `Content-Type: application/json` (or `multipart/form-data` if uploading file `image`)
- **JSON Request Body:**
```json
{
  "name": "Bespoke Outerwear",
  "slug": "bespoke-outerwear",
  "description": "Hand-tailored cashmere and virgin wool coats",
  "imageUrl": "https://images.unsplash.com/photo-1544022613-e87ca75a784a?w=800",
  "parentId": "c1a2b3c4-0000-0000-0000-000000000001",
  "sortOrder": 2,
  "isFeatured": true,
  "isActive": true
}
```
- **Validation Rules:**
  - `name`: String, 2 to 100 characters (Required).
  - `slug`: Optional URL-safe string. If omitted, generated automatically from `name`.
  - `parentId`: Optional UUID of parent category (must be a valid existing category).
  - `sortOrder`: Optional integer (Default: `0`).
  - `isFeatured`: Optional boolean (Default: `false`).
  - `isActive`: Optional boolean (Default: `true`).
- **Response `201 Created`:**
```json
{
  "success": true,
  "statusCode": 201,
  "message": "Category created successfully",
  "data": {
    "category": {
      "id": "cat_uuid_10",
      "name": "Bespoke Outerwear",
      "slug": "bespoke-outerwear",
      "description": "Hand-tailored cashmere and virgin wool coats",
      "imageUrl": "https://images.unsplash.com/photo-1544022613-e87ca75a784a?w=800",
      "parentId": "c1a2b3c4-0000-0000-0000-000000000001",
      "sortOrder": 2,
      "isFeatured": true,
      "isActive": true,
      "parent": {
        "id": "c1a2b3c4-0000-0000-0000-000000000001",
        "name": "Women",
        "slug": "women"
      },
      "createdAt": "2026-10-10T00:00:00.000Z"
    }
  }
}
```

### 2.4. Update Category
Updates an existing category. Includes circular parent detection.

- **Endpoint:** `PUT /api/v1/admin/categories/:id`
- **Headers:** `Authorization: Bearer <token>`
- **Request Body (all fields optional):**
```json
{
  "name": "Haute Outerwear",
  "description": "Updated winter collection luxury outerwear",
  "sortOrder": 3,
  "isFeatured": false
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Category updated successfully",
  "data": {
    "category": {
      "id": "cat_uuid_10",
      "name": "Haute Outerwear",
      "slug": "haute-outerwear",
      "sortOrder": 3,
      "isFeatured": false,
      "productCount": 0,
      "childrenCount": 0
    }
  }
}
```

---

### 2.5. Delete Category
- **Endpoint:** `DELETE /api/v1/admin/categories/:id`
- **Query Parameters:**
  - `force`: `"false"` (default) or `"true"` (bypasses product/children block)
- **Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Category deleted successfully",
  "data": {
    "id": "cat_uuid_10",
    "name": "Haute Outerwear",
    "deleted": true
  }
}
```

### 3.3. Create Collection
- **Endpoint:** `POST /api/v1/admin/collections`
- **Headers:**
  - `Authorization: Bearer <token>`
  - `Content-Type: application/json` (or `multipart/form-data` with `image`)
- **JSON Request Body:**
```json
{
  "name": "Monsoon Linen Capsule",
  "slug": "monsoon-linen-capsule",
  "description": "Breathable pure Irish linen separates",
  "imageUrl": "https://images.unsplash.com/photo-1515886657613-9f3515b0c78f?w=1200",

  "sortOrder": 1,
  "isActive": true,
  "productIds": ["prod_uuid_101", "prod_uuid_102"]

```

### 3.5. Reorder & Sync Products in Collection
Replaces and sequences all products in the collection with the provided array of product IDs.

- **Endpoint:** `PUT /api/v1/admin/collections/:id/products`
- **Headers:** `Authorization: Bearer <token>`
- **Request Body:**
```json
{
  "productIds": [
    "prod_uuid_102",
    "prod_uuid_101",
    "prod_uuid_105"
  ]
}
```
- **Response `200 OK`:** Returns collection with products sequenced in the exact array index order.

---

### 3.6. Add Products to Collection
Appends products without removing existing ones.

- **Endpoint:** `POST /api/v1/admin/collections/:id/products`
- **Headers:** `Authorization: Bearer <token>`
- **Request Body:**
```json
{
  "productIds": ["prod_uuid_108", "prod_uuid_109"]
}
```

---

### 3.7. Remove Single Product from Collection
- **Endpoint:** `DELETE /api/v1/admin/collections/:id/products/:productId`
- **Headers:** `Authorization: Bearer <token>`
- **Response `200 OK`:** `{ "collectionId": "...", "productId": "...", "removed": true }`

---

### 3.8. Delete Collection
- **Endpoint:** `DELETE /api/v1/admin/collections/:id`
- **Headers:** `Authorization: Bearer <token>`
- **Response `200 OK`:** `{ "id": "...", "name": "...", "deleted": true }`

## 4. Error Handling Reference for Frontend

| Status Code | Error Code | Cause | Recommended Frontend Handling |
| :--- | :--- | :--- | :--- |
| **`400 Bad Request`** | `CIRCULAR_HIERARCHY_SELF` | User selected category itself as parent. | Disable category from parent dropdown. |
| **`400 Bad Request`** | `CIRCULAR_HIERARCHY_DESCENDANT` | User selected a subcategory as parent. | Filter out all child categories from parent dropdown. |
| **`400 Bad Request`** | `CATEGORY_CONTAINS_PRODUCTS` | Tried deleting category with products without `?force=true`. | Show warning modal: "Category has 14 products. Reassign them first." |
| **`400 Bad Request`** | `CATEGORY_CONTAINS_CHILDREN` | Tried deleting category with subcategories without `?force=true`. | Show warning modal: "Please reassign or delete subcategories first." |
| **`403 Forbidden`** | `FORBIDDEN_INSUFFICIENT_PERMISSIONS` | Staff user lacks `categories:manage` or `collections:manage`. | Show toast: "Administrative permission required." |
| **`404 Not Found`** | `CATEGORY_NOT_FOUND` / `COLLECTION_NOT_FOUND` | ID does not exist. | Redirect back to list page or show 404 drawer. |
| **`409 Conflict`** | `DUPLICATE_CATEGORY_NAME` | Another category under same parent has the same name. | Show inline error under category name field. |
| **`429 Too Many Requests`** | `RATE_LIMIT_EXCEEDED` | Request limit exceeded. | Toast notification to wait. |
