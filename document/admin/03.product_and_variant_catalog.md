# Module 03: Product & Multi-Variant Catalog Management API

> **Module:** 03 - Product & Multi-Variant Catalog Management  
> **Audience:** Frontend Development Team (`/admin/products`)  
> **Base URL:** `/api/v1/admin/products`  
> **Auth Required:** `Authorization: Bearer <accessToken>`  
> **Required Permissions:**  
> - Read: `products:read`  
> - Create/Edit: `products:write`  
> - Delete: `products:delete`  
> *(Automatic root bypass for `SUPER_ADMIN`)*  

---

## 1. Overview & Architecture

This module handles luxury apparel garments, multi-variant sizing (`S`, `M`, `L`, `XL`), color hex swatches, image galleries, and pricing:

1. **Multi-Variant Sizing & Swatches:**
   - Products can have simple stock **OR** multiple variant combinations (e.g. `Size: M` + `Color: Midnight Navy`).
   - Sizing and Color swatches are automatically linked to `Attribute` and `AttributeValue` entities.
   - When variants are added, the product's total `stockQuantity` is automatically computed as the sum of variant stock.
2. **Pricing Structure:**
   - `regularPrice`: Original / compare-at price (Mandatory).
   - `salePrice`: Discounted price (Optional).
   - `offerPrice`: Special flash promo price (Optional).
   - `costPrice`: Cost of goods sold (COGS) for internal profit margin calculation (Admin-only).
3. **Safe Archiving & Deletion:**
   - If a product is already present in customer carts or order history, calling `DELETE` automatically **soft-archives** the garment (`isActive: false`) to safeguard historical invoices and receipts.
4. **Cloud-Only Image Pipeline:**
   - Zero local disk storage: Images can be supplied as existing URLs **OR** uploaded as files via `multipart/form-data` (`images`), which stream directly to Cloudinary.

## 2. API Endpoints Specification

### 2.1. List Products (Faceted Filters & Pagination)
Retrieves paginated products for the main admin table with rich filtering and sorting.

- **Endpoint:** `GET /api/v1/admin/products`
- **Headers:** `Authorization: Bearer <token>`
- **Query Parameters:**
  - `page`: Page number (Default: `1`)
  - `limit`: Items per page (Default: `20`, Max: `100`)
  - `search`: Searches across product name, SKU, brand, and slug
  - `categoryId`: Filter by category (includes all subcategories automatically)
  - `brand`: Filter by brand name
  - `isActive`: `"true"` or `"false"`
  - `isFeatured`: `"true"` or `"false"`
  - `stockStatus`: `"IN_STOCK"` (> 0), `"LOW_STOCK"` (1 to 5), `"OUT_OF_STOCK"` (= 0)
  - `minPrice`: Minimum regular price
  - `maxPrice`: Maximum regular price
  - `sort`: `"newest"` (default), `"oldest"`, `"price_asc"`, `"price_desc"`, `"stock_asc"`, `"stock_desc"`, `"name_asc"`, `"bestselling"`
- **Example Request:**
  `GET /api/v1/admin/products?page=1&limit=10&stockStatus=LOW_STOCK&sort=newest`

### 2.3. Create Product
Creates a garment with variants, attributes, and images in an atomic database transaction.

- **Endpoint:** `POST /api/v1/admin/products`
- **Headers:**
  - `Authorization: Bearer <token>`
  - `Content-Type: application/json` (or `multipart/form-data` if attaching image files)
- **JSON Request Body:**
```json
{
  "name": "Italian Virgin Wool Double-Breasted Blazer",
  "slug": "italian-virgin-wool-double-breasted-blazer",
  "description": "Tailored in Biella wool with horn buttons and peak lapels.",
  "brand": "Maison De Élégance",
  "sku": "BLZ-002",
  "categoryId": "c1a2b3c4-0000-0000-0000-000000000001",
  "regularPrice": 29999,
  "salePrice": 24999,
  "costPrice": 12000,
  "isActive": true,
  "isFeatured": true,
  "images": [
    {
      "url": "https://images.unsplash.com/photo-1507679799987-c73779587ccf?w=800",
      "altText": "Blazer Front Angle",
      "isThumbnail": true,
      "sortOrder": 0
    }
  ],
  "variants": [
    {
      "sku": "BLZ-002-38R-NVY",
      "name": "38R - Midnight Navy",
      "regularPrice": 29999,
      "salePrice": 24999,
      "costPrice": 12000,
      "stockQuantity": 8,
      "size": "38R",
      "color": "Midnight Navy",
      "colorHex": "#0b1b3d",
      "isActive": true
    },
    {
      "sku": "BLZ-002-40R-NVY",
      "name": "40R - Midnight Navy",
      "regularPrice": 29999,
      "salePrice": 24999,
      "costPrice": 12000,
      "stockQuantity": 10,
      "size": "40R",
      "color": "Midnight Navy",
      "colorHex": "#0b1b3d",
      "isActive": true
    }
  ]
}
```
- **Validation Rules:**
  - `name`: String, 2 to 200 characters (Required).
  - `categoryId`: Valid category UUID (Required).
  - `regularPrice`: Number >= 0 (Required).
  - `salePrice`: Optional number <= regularPrice.
  - `variants`: Optional array. If provided, variant `sku` must be unique. Total product stock will equal the sum of variant stock.
- **Response `201 Created`:** Returns full product record with variants and attributes.

### 2.4. Update Product
Updates product details, adjusts prices, or updates variants.

- **Endpoint:** `PUT /api/v1/admin/products/:id`
- **Headers:** `Authorization: Bearer <token>`
- **Request Body (all fields optional):**
```json
{
  "name": "Italian Biella Wool Double-Breasted Blazer",
  "salePrice": 22999,
  "isFeatured": true,
  "variants": [
    {
      "id": "var_uuid_existing",
      "sku": "BLZ-002-38R-NVY",
      "stockQuantity": 12,
      "salePrice": 22999
    }
  ]
}
```
- **Response `200 OK`:** Returns updated product.

### 2.5. Quick Status Toggle
Fast toggle for Active or Featured status without needing the full update body.

- **Endpoint:** `PATCH /api/v1/admin/products/:id/status`
- **Headers:** `Authorization: Bearer <token>`
- **Request Body:**
```json
{
  "isActive": false,
  "isFeatured": true
}
```
- **Response `200 OK`:**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Product status updated successfully",
  "data": {
    "id": "prod_uuid_101",
    "name": "Italian Virgin Wool Double-Breasted Blazer",
    "isActive": false,
    "isFeatured": true,
    "updatedAt": "2026-10-10T00:30:00.000Z"
  }
}
```

### 2.6. Delete / Archive Product
- **Endpoint:** `DELETE /api/v1/admin/products/:id`
- **Query Parameters:**
  - `force`: `"false"` (default) or `"true"`
- **Response `200 OK` (Soft-Archived if active in customer carts):**
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Product \"Mulberry Silk Draped Evening Gown\" is present in customer carts and was archived (set to inactive) instead of deleted.",
  "data": {
    "id": "prod_uuid_101",
    "name": "Mulberry Silk Draped Evening Gown",
    "action": "ARCHIVED"
  }
}
```

---

### 2.7. Upload Additional Product Images
Uploads multiple gallery images directly to an existing product via Cloudinary stream.

- **Endpoint:** `POST /api/v1/admin/products/:id/images`
- **Headers:**
  - `Authorization: Bearer <token>`
  - `Content-Type: multipart/form-data`
- **Form Data:**
  - `images`: 1 to 5 image files (`JPEG`, `PNG`, `WEBP`)
  - `isThumbnail`: `"true"` or `"false"` (optional)
  - `altText`: Description (optional)
- **Response `201 Created`:**
```json
{
  "success": true,
  "statusCode": 201,
  "message": "2 image(s) uploaded successfully",
  "data": {
    "images": [
      {
        "id": "img_uuid_55",
        "productId": "prod_uuid_101",
        "url": "https://res.cloudinary.com/.../gown_back.webp",
        "altText": "Product image",
        "isThumbnail": false,
        "sortOrder": 0
      }
    ]
  }
}
```

### 2.8. Delete Product Image
- **Endpoint:** `DELETE /api/v1/admin/products/:id/images/:imageId`
- **Headers:** `Authorization: Bearer <token>`
- **Response `200 OK`:** `{ "productId": "...", "imageId": "...", "deleted": true }`

## 3. Frontend Error Handling Guide

| Status Code | Error Code | Cause | Frontend Action |
| :--- | :--- | :--- | :--- |
| **`400 Bad Request`** | `VALIDATION_ERROR` | Price negative, or missing name/category. | Highlight fields with inline red helper text. |
| **`403 Forbidden`** | `FORBIDDEN_INSUFFICIENT_PERMISSIONS` | Staff user lacks `products:write` or `products:delete`. | Show warning toast: "Permission required to edit products." |
| **`404 Not Found`** | `PRODUCT_NOT_FOUND` / `CATEGORY_NOT_FOUND` | ID does not exist in database. | Show 404 drawer or redirect to list. |
| **`409 Conflict`** | `DUPLICATE_SKU` | Product SKU is already assigned to another garment. | Highlight SKU input: "SKU already in use." |
| **`409 Conflict`** | `DUPLICATE_VARIANT_SKU` | Variant SKU matches an existing variant. | Highlight specific variant row SKU. |
| **`429 Too Many Requests`** | `RATE_LIMIT_EXCEEDED` | Exceeded 300 requests in 15 mins. | Show toast to wait a moment. |
