# Customer Password Recovery & Contact Concierge API Reference

**Document:** `document/customer/07.forget_pass_&_contact_api_details.md`  
**Target:** Frontend Implementation (AI & Engineers)  
**Base URL:** `http://localhost:5000/api/v1` (alias `/api` supported)  
**Auth:** None required (Public endpoints)  

---

## 1. Flow & User Journey Summary

```
[Forgot Password Page]   --> POST /auth/forgot-password   --> Dispatches reset email
[Customer Inbox]         --> Clicks link in email         --> /reset-password?token=...&email=...
[Reset Password Page]    --> POST /auth/reset-password    --> Resets password, invalidates sessions
[Contact Page / Modal]   --> POST /contact                --> Stores inquiry & notifies staff/customer
```

### Route Mapping
| Page / Trigger | Frontend Route | Backend Endpoint | Method |
| :--- | :--- | :--- | :--- |
| **Forgot Password** | `/forgot-password` | `/api/v1/auth/forgot-password` | `POST` |
| **Reset Password** | `/reset-password?token={token}&email={email}` | `/api/v1/auth/reset-password` | `POST` |
| **Contact Concierge** | `/contact` | `/api/v1/contact` | `POST` |

## 3. API Endpoints Specification

### 3.1 Forgot Password
* **Path:** `POST /api/v1/auth/forgot-password`
* **Rate Limit:** 10 requests / 15 minutes per IP
* **Description:** Generates a secure single-use token valid for **1 hour** and sends a reset link to the email.
* **Security:** Always returns `200 OK` (anti-enumeration protection) whether the email exists or not.

#### Request Body
```json
{
  "email": "customer@example.com"
}
```

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "message": "If an account exists with that email, a password reset link has been dispatched."
}
```

#### Error Response (`400 Bad Request`)
```json
{
  "success": false,
  "message": "Please provide a valid email address",
  "error": { "code": "VALIDATION_ERROR", "details": [{ "field": "email", "message": "Please provide a valid email address" }] }
}
```

---

### 3.2 Reset Password
* **Path:** `POST /api/v1/auth/reset-password`
* **Description:** Verifies token, hashes new password with bcrypt, deletes token, and invalidates all existing refresh token sessions.

#### Request Body
```json
{
  "email": "customer@example.com",
  "token": "4f9d8a2b1c3e5f7a9d8a2b1c3e5f7a9d8a2b1c3e5f7a9d8a2b1c3e5f7a9d8a2b",
  "newPassword": "NewPassword123"
}
```

#### Password Rules
- Length: 8 to 100 characters
- Must contain at least one letter and at least one number
- Regex: `/^(?=.*[A-Za-z])(?=.*\d).{8,100}$/`

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "message": "Password has been successfully reset. Please log in with your new credentials."
}
```

#### Error Responses
- **Token expired or already used (`400 Bad Request`):**
  ```json
  {
    "success": false,
    "message": "Invalid or expired password reset link. Please request a new one.",
    "error": { "code": "INVALID_OR_EXPIRED_RESET_TOKEN" }
  }
  ```
- **Validation error (`400 Bad Request`):**
  ```json
  {
    "success": false,
    "message": "New password must contain at least one number",
    "error": { "code": "VALIDATION_ERROR", "details": [{ "field": "newPassword", "message": "New password must contain at least one number" }] }
  }
  ```

### 3.3 Contact Concierge / Support Inquiry
* **Path:** `POST /api/v1/contact`
* **Description:** Persists inquiry in database, sends email alert to store support, and sends confirmation email to customer.

#### Request Body
```json
{
  "name": "Priya Sharma",
  "email": "priya.sharma@example.com",
  "phone": "9876543210",
  "subject": "Inquiry regarding custom evening gown",
  "message": "Hello, I would like to inquire about bespoke sizing for wedding guest dresses."
}
```

| Field | Type | Required | Constraints |
| :--- | :--- | :--- | :--- |
| `name` | `string` | Yes | 2 – 100 chars |
| `email` | `string` | Yes | Valid email format |
| `phone` | `string` | No | Max 25 chars (or null) |
| `subject` | `string` | Yes | 3 – 200 chars |
| `message` | `string` | Yes | 10 – 3000 chars |

#### Success Response (`201 Created`)
```json
{
  "success": true,
  "message": "Thank you for reaching out. Our concierge team has received your message and will respond shortly.",
  "data": {
    "inquiry": {
      "id": "5309d2ec-4d68-49e4-9856-880a80c7e769",
      "name": "Priya Sharma",
      "email": "priya.sharma@example.com",
      "subject": "Inquiry regarding custom evening gown",
      "createdAt": "2026-10-17T13:00:01.160Z"
    }
  }
}
```

## 4. Frontend Query Parameter Handling

The email link sends the user to:  
`https://your-domain.com/reset-password?token={RAW_TOKEN}&email={USER_EMAIL}`

### Next.js App Router
```tsx
'use client';
import { useSearchParams } from 'next/navigation';

export function useResetPasswordParams() {
  const searchParams = useSearchParams();
  return {
    token: searchParams.get('token') || '',
    email: searchParams.get('email') || '',
  };
}
```

## 5. Frontend Implementation Code Examples

### 5.1 API Client Helper (`api.ts`)
```typescript
const BASE_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:5000/api/v1';

async function request<T>(endpoint: string, options: RequestInit): Promise<T> {
  const res = await fetch(`${BASE_URL}${endpoint}`, {
    headers: { 'Content-Type': 'application/json' },
    ...options,
  });
  const data = await res.json();
  if (!res.ok) throw data;
  return data;
}

export const authApi = {
  forgotPassword: (email: string) =>
    request('/auth/forgot-password', { method: 'POST', body: JSON.stringify({ email }) }),

  resetPassword: (payload: { email: string; token: string; newPassword: string }) =>
    request('/auth/reset-password', { method: 'POST', body: JSON.stringify(payload) }),

  submitContact: (payload: { name: string; email: string; phone?: string; subject: string; message: string }) =>
    request('/contact', { method: 'POST', body: JSON.stringify(payload) }),
};
```

### 5.2 Forgot Password Component
```tsx
import React, { useState } from 'react';
import { authApi } from './api';

export const ForgotPassword = () => {
  const [email, setEmail] = useState('');
  const [sent, setSent] = useState(false);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    setError('');
    try {
      await authApi.forgotPassword(email);
      setSent(true);
    } catch (err: any) {
      setError(err.message || 'Request failed');
    } finally {
      setLoading(false);
    }
  };

  if (sent) {
    return <p>If an account exists for {email}, a reset link has been dispatched to your inbox (valid 1 hour).</p>;
  }

  return (
    <form onSubmit={handleSubmit}>
      <h2>Forgot Password</h2>
      {error && <p className="error">{error}</p>}
      <input type="email" required placeholder="Enter email" value={email} onChange={(e) => setEmail(e.target.value)} />
      <button type="submit" disabled={loading}>{loading ? 'Sending...' : 'Send Reset Link'}</button>
    </form>
  );
};
```

### 5.3 Reset Password Component
```tsx
import React, { useState } from 'react';
import { authApi } from './api';

export const ResetPassword = ({ token, email }: { token: string; email: string }) => {
  const [newPassword, setNewPassword] = useState('');
  const [confirmPassword, setConfirmPassword] = useState('');
  const [loading, setLoading] = useState(false);
  const [success, setSuccess] = useState(false);
  const [error, setError] = useState('');

  if (!token || !email) {
    return <p className="error">Invalid or missing reset token. Please request a new reset link.</p>;
  }

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (newPassword !== confirmPassword) return setError('Passwords do not match');
    if (!/^(?=.*[A-Za-z])(?=.*\d).{8,100}$/.test(newPassword)) {
      return setError('Password must be 8+ chars and contain both letters and numbers');
    }

    setLoading(true);
    setError('');
    try {
      await authApi.resetPassword({ email, token, newPassword });
      setSuccess(true);
    } catch (err: any) {
      setError(err.message || 'Reset failed');
    } finally {
      setLoading(false);
    }
  };

  if (success) {
    return <p>Password reset complete! <a href="/login">Login here</a></p>;
  }

  return (
    <form onSubmit={handleSubmit}>
      <h2>Reset Password for {email}</h2>
      {error && <p className="error">{error}</p>}
      <input type="password" required placeholder="New Password (min 8 chars, letters & numbers)" value={newPassword} onChange={(e) => setNewPassword(e.target.value)} />
      <input type="password" required placeholder="Confirm Password" value={confirmPassword} onChange={(e) => setConfirmPassword(e.target.value)} />
      <button type="submit" disabled={loading}>{loading ? 'Updating...' : 'Set New Password'}</button>
    </form>
  );
};
```

### 5.4 Contact Concierge Component
```tsx
import React, { useState } from 'react';
import { authApi } from './api';

export const ContactForm = () => {
  const [form, setForm] = useState({ name: '', email: '', phone: '', subject: '', message: '' });
  const [loading, setLoading] = useState(false);
  const [done, setDone] = useState(false);
  const [error, setError] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    setError('');
    try {
      await authApi.submitContact(form);
      setDone(true);
    } catch (err: any) {
      setError(err.message || 'Submission failed');
    } finally {
      setLoading(false);
    }
  };

  if (done) return <p>Thank you! Our concierge team has received your message and will respond shortly.</p>;

  return (
    <form onSubmit={handleSubmit}>
      <h2>Contact Concierge</h2>
      {error && <p className="error">{error}</p>}
      <input placeholder="Name *" required value={form.name} onChange={(e) => setForm({ ...form, name: e.target.value })} />
      <input type="email" placeholder="Email *" required value={form.email} onChange={(e) => setForm({ ...form, email: e.target.value })} />
      <input placeholder="Phone (optional)" value={form.phone} onChange={(e) => setForm({ ...form, phone: e.target.value })} />
      <input placeholder="Subject *" required value={form.subject} onChange={(e) => setForm({ ...form, subject: e.target.value })} />
      <textarea rows={4} placeholder="Message (min 10 chars) *" required minLength={10} value={form.message} onChange={(e) => setForm({ ...form, message: e.target.value })} />
      <button type="submit" disabled={loading}>{loading ? 'Submitting...' : 'Send Message'}</button>
    </form>
  );
};
```
