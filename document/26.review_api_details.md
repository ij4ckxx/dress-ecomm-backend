## 1. Architecture & Core Workflow Overview

The **Product Reviews & Ratings Engine** is designed specifically for luxury garment and dress e-commerce. It incorporates customer trust badges, size/fit feedback, user photo galleries, review upvoting, and admin moderation controls.

```
+-----------------------------------------------------------------------------------------------------------------------+
|                                              REVIEW ENGINE ARCHITECTURE                                               |
+-----------------------------------------------------------------------------------------------------------------------+
|                                                                                                                       |
|   1. PRODUCT DETAILS PAGE (PDP)                  2. CUSTOMER ACCOUNT DASHBOARD             3. ADMIN MODERATION PANEL  |
|   Route: /products/:slug                         Route: /account/reviews                   Route: /admin/reviews      |
|   - Rating overview (Avg, total count)           - List my past reviews                    - Moderation queue         |
|   - 5-Star distribution progress bars            - Products awaiting review                - Status toggle            |
|   - Fit feedback meter (True to Size %)          - Edit / delete my review                 - Official store replies   |
|   - User photo gallery                           - Track helpful upvotes                   - Rating analytics         |
|   - Helpful vote button ("Was this helpful?")                                                                         |
|                                                                                                                       |
|                                     +-----------------------------------------+                                       |
|                                     |    BACKEND SERVICE LAYER (/api/v1)      |                                       |
|                                     +-----------------------------------------+                                       |
|                                                          |                                                            |
|                           +------------------------------+------------------------------+                             |
|                           |                                                             |                             |
|                           v                                                             v                             |
|            4. VERIFIED PURCHASE CHECK                                    5. ATOMIC RATING ENGINE                      |
|            - Checks orders for userId + productId                        - Computes avg rating & reviewCount          |
|            - Requires orderStatus: 'DELIVERED'                           - Exclusively counts APPROVED reviews        |
|            - Displays "Verified Buyer" badge                             - Updates Product table in atomic tx         |
+-----------------------------------------------------------------------------------------------------------------------+
```

### Key Architectural Highlights:
1. **Dual Image Input Architecture (Optional)**:
   - **Direct File Upload**: Upload up to 10 image files (`.jpg`, `.png`, `.webp`) via `multipart/form-data` under the field name `images` or `files`. The backend streams them directly to Cloudinary (folder: `dresses/reviews`).
   - **Pre-hosted Image URLs**: Pass an array of URLs (or a JSON string) under `images` in `application/json` or `multipart/form-data`.
   - Both modes are mutually exclusive per request to prevent accidental duplicate submission.
2. **Verified Buyer Badge (`isVerifiedPurchase`)**:
   - The backend automatically checks if the reviewing customer has an order containing this product that has reached the `DELIVERED` status.
   - If true, `isVerifiedPurchase: true` is permanently tagged and linked to `orderId`.
3. **Apparel Sizing & Fit Feedback (`fitFeedback`)**:
   - Customers can specify: `RUNS_SMALL`, `TRUE_TO_SIZE`, or `RUNS_LARGE`.
   - The PDP review summary provides aggregated percentages so shoppers know how the dress fits before purchasing.
4. **Instant Publishing with Moderation**:
   - Reviews are auto-approved (`status: 'APPROVED'`) upon submission so customers see their review immediately.
   - Store admins can flag, reject, or delete inappropriate/spam reviews at any time.
5. **Helpful Upvote System**:
   - Customers can vote reviews as "Helpful" (`POST /reviews/:id/vote`). Toggling is supported (calling again removes the vote). Authors cannot vote on their own reviews.

### 2.1 Get Product Reviews & Rating Summary Breakdown
* **Endpoints:**
  - `GET https://dress-ecomm-backend.onrender.com/api/v1/products/:slug/reviews`
  - `GET https://dress-ecomm-backend.onrender.com/api/v1/reviews/products/:slugOrId`
* **Authentication:** Optional (`Authorization: Bearer <customerAccessToken>`). If provided, returns `hasVoted: true/false` indicating whether the logged-in customer has upvoted each review.
* **Frontend Screen:** Product Details Page (PDP) — Reviews & Ratings Tab / Section.

#### Query Parameters:
| Parameter | Type | Default | Description |

| `sortBy` | String | `newest` | Sort by: `newest`, `oldest`, `highest_rating`, `lowest_rating`, `most_helpful` |

```bash
curl -X GET "https://dress-ecomm-backend.onrender.com/api/v1/products/empress-velvet-gala-gown/reviews?page=1&limit=10&sortBy=most_helpful" \
```

### 2.2 Submit Customer Review
* **Endpoints:**
  - `POST https://dress-ecomm-backend.onrender.com/api/v1/products/:id/reviews`
  - `POST https://dress-ecomm-backend.onrender.com/api/v1/reviews/products/:id`
* **Authentication:** Required (`Authorization: Bearer <customerAccessToken>`)
* **Content-Type Options:**
  - **Option 1 (`application/json`):** For submitting review text and optional image URLs.
  - **Option 2 (`multipart/form-data`):** For uploading photos directly from device camera/gallery to Cloudinary.

#### Request Body Fields:
| Field | Type | Required? | Description |
| :--- | :--- | :--- | :--- |
| `rating` | Integer | **Required** | Star rating between `1` and `5` |
| `comment` | String | **Required** | Detailed customer feedback (min 3 chars, max 3000 chars) |
| `title` | String | Optional | Short headline for the review (max 150 chars) |
| `fitFeedback`| String | Optional | Sizing feedback: `'RUNS_SMALL'`, `'TRUE_TO_SIZE'`, or `'RUNS_LARGE'` |
| `images` | Array of Strings / Files | Optional | Either pre-hosted URLs array OR binary files attached as `images` (max 10) |

#### Example 1 — Submitting via `application/json` (with Image URLs):
```bash
curl -X POST "https://dress-ecomm-backend.onrender.com/api/v1/products/2181f24e-9891-4473-b0cf-9355a2ef599c/reviews" \
  -H "Authorization: Bearer <CUSTOMER_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "rating": 5,
    "title": "Breathtaking Fit and Color",
    "comment": "The emerald shade is stunning in natural lighting. True to size and high quality lining.",
    "fitFeedback": "TRUE_TO_SIZE",
    "images": [
      "https://example.com/my-dress-pic-1.jpg"
    ]
  }'
```

#### Example 2 — Submitting via `multipart/form-data` (Direct File Upload to Cloudinary):
```bash
curl -X POST "https://dress-ecomm-backend.onrender.com/api/v1/products/2181f24e-9891-4473-b0cf-9355a2ef599c/reviews" \
  -H "Authorization: Bearer <CUSTOMER_TOKEN>" \
  -F "rating=5" \
  -F "title=Stunning dress for graduation" \
  -F "comment=Super flattering silhouette and luxurious fabric. Loved it!" \
  -F "fitFeedback=TRUE_TO_SIZE" \
  -F "images=@/path/to/dress_photo1.jpg" \
  -F "images=@/path/to/dress_photo2.jpg"
```

### 2.6 Delete Customer Review
* **Endpoint:** `DELETE https://dress-ecomm-backend.onrender.com/api/v1/reviews/:id`
* **Authentication:** Required (`Authorization: Bearer <customerAccessToken>`)
* **Effect:** Deletes the review and automatically recalculates the product's average rating and review count.

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "message": "Review deleted successfully",
  "data": {
    "id": "8ba12079-c3b0-466d-9642-132d7f9556a1",
    "deleted": true
  }
}
```

### 2.7 Upvote / Toggle "Was this helpful?"
* **Endpoint:** `POST https://dress-ecomm-backend.onrender.com/api/v1/reviews/:id/vote`
* **Authentication:** Required (`Authorization: Bearer <customerAccessToken>`)
* **Logic:** 
  - Calling this the first time creates an upvote (`hasVoted: true`, `helpfulCount + 1`).
  - Calling this again removes the upvote (`hasVoted: false`, `helpfulCount - 1`).
  - Authors cannot vote on their own review (returns `400 Bad Request`).

#### Success Response (`200 OK`):
```json
{
  "success": true,
  "message": "Thank you for your feedback! Review marked as helpful.",
  "data": {
    "reviewId": "ec4bd4c4-177b-4a44-bde3-88c93ed61d25",
    "hasVoted": true,
    "helpfulCount": 13
  }
}
```

## 3. Admin Panel APIs Reference (`/api/v1/admin/reviews`)

## 4. Frontend Component Mapping & Best Practices

| Frontend Component / Screen | Target Endpoint | Recommended Usage Pattern |
| :--- | :--- | :--- |
| **PDP Rating Summary (Header & Stars)** | `GET /products/:slug/reviews` | Use `data.summary.averageRating` and `data.summary.totalReviews` to render the star widget near the price. |
| **PDP 5-Star Breakdown Progress Bars** | `GET /products/:slug/reviews` | Map `data.summary.ratingBreakdown[star].percentage` to 5 colored progress bars. |
| **PDP Sizing Meter ("Runs Small / True to Size / Runs Large")** | `GET /products/:slug/reviews` | Use `data.summary.fitBreakdown` to render a 3-way slider showing what percentage of customers felt it was True to Size. |
| **Write Review Modal / Drawer** | `POST /products/:id/reviews` | Support direct file selection for dress photos. If user picks photos, send as `multipart/form-data` with `images`. |
| **Helpful Upvote Button ("Was this helpful?")** | `POST /reviews/:id/vote` | Optimistically increment/decrement the upvote count and toggle the icon style based on `data.hasVoted`. |
| **Customer Dashboard "My Reviews" Tab** | `GET /reviews/my-reviews` | Display garments reviewed by the customer with edit & delete action menus. |
| **Customer "Items Pending Review" Banner** | `GET /reviews/pending` | Show a polite banner after order delivery: *"How was your recent purchase? Write a review & get 50 loyalty points."* |
| **Admin Moderation Portal** | `GET /admin/reviews` | Table displaying reviews with status filter pill tabs (`Pending (6)`, `Approved (118)`, `Rejected (3)`). |
| **Admin Quick Action Menu** | `PATCH /admin/reviews/:id/status` | Instant one-click buttons to Approve, Flag, or Reject. |
| **Admin Store Reply Modal** | `POST /admin/reviews/:id/reply` | Simple text area for replying to customer feedback. |
