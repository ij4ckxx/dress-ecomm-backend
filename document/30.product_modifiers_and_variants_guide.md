## 1. Executive Summary & Architecture

In modern e-commerce platforms like **BigCommerce Catalyst**, products require two distinct customization dimensions:

1. **Product Variants (SKU-Level Variations):**
   - Represents physical stock-keeping units (e.g., Size: `S`, `M`, `L`, `XL`; Color: `Emerald Green`, `Midnight Black`).
   - Each variant has its own dedicated `sku`, `stockQuantity`, `regularPrice`, `salePrice`, `offerPrice`, and gallery images.
   - Selecting a variant switches the product's base price and checks atomic SKU inventory.

2. **Product Modifiers (Customization-Level Variations):**
   - Allows customers to personalize a garment **without** creating separate inventory SKUs.
   - Supports 9 distinct UI control types: dropdowns, radio buttons, rectangle swatch buttons, checkboxes, text boxes (monograms/embroidery), multi-line notes, numeric inputs (custom measurements), date pickers, and file uploads.
   - Options can carry a positive or negative price adjustment (`priceDelta`), dynamically altering the product unit price.

### Dynamic Pricing Formula

```
+---------------------------------------------------------------------------------------------------------+
|                                        DYNAMIC PRICING FORMULA                                          |
+---------------------------------------------------------------------------------------------------------+
|                                                                                                         |
|   1. Base Item Price:                                                                                   |
|      If variant selected:   Base Price = variant.salePrice ?? variant.regularPrice                     |
|      If no variant:         Base Price = product.salePrice ?? product.regularPrice                     |
|                                                                                                         |
|   2. Modifier Delta Total:                                                                              |
|      Modifier Total = Sum(selectedModifierOption.priceDelta)                                            |
|                                                                                                         |
|   3. Effective Unit Price:                                                                              |
|      Unit Price = Base Price + Modifier Total                                                           |
|                                                                                                         |
|   4. Line Total:                                                                                        |
|      Line Total = Unit Price * Quantity                                                                 |
|                                                                                                         |
+---------------------------------------------------------------------------------------------------------+
```

## 2. Comparison: Variants vs Modifiers

| Dimension | Product Variants | Product Modifiers |
| :--- | :--- | :--- |
| **Primary Purpose** | Defines distinct purchasable garments (Size & Color). | Adds customer customizations, accessories, and gifts. |
| **Inventory Tracking** | **Tracked individually per SKU** in `ProductVariant` table. | Not tracked per SKU (inherits base garment inventory). |
| **Price Effect** | **Overrides Base Price** (`variant.salePrice` replaces `product.salePrice`). | **Adds/Subtracts Deltas** (`priceDelta: +350` adds ₹350 to base price). |
| **UI Components** | Size selector buttons, color swatches. | Dropdowns, radio buttons, rectangle lists, checkboxes, text fields, textareas, date pickers. |
| **Free-Form Inputs** | No (predefined catalog attributes only). | **Yes** (custom monograms, gift messages, custom body lengths). |
| **Order Storage** | Saved as `OrderItem.variantId`, `OrderItem.size`, `OrderItem.color`. | Snapshotted as structured JSON in `OrderItem.modifiers`. |

## 3. Supported Catalyst Modifier Types

The database enum `ModifierType` supports 9 UI types:

| Type Key | Recommended Storefront UI Component | Example Use Cases | Supported Attributes |
| :--- | :--- | :--- | :--- |
| `DROPDOWN` | HTML `<select>` or custom dropdown | Matching Belt selection, Neckline style | `options` with `name`, `priceDelta`, `isDefault` |
| `RADIO_BUTTONS` | Radio group `(●) Option` | Lining material (Silk vs Satin), Hem length | `options` with `name`, `priceDelta`, `isDefault` |
| `RECTANGLE_LIST` | Pill / Button group tiles | Sleeve style, Collar cut, Border embroidery | `options` with `name`, `priceDelta`, `isDefault` |
| `CHECKBOX` | Single toggle checkbox `[✓]` | "Add Luxury Velvet Gift Box (+₹250)", "Rush Tailoring (+₹500)" | `options` (single or multi-select), `defaultValue` |
| `SHORT_TEXT` | Single-line `<input type="text">` | Embroidered initials / Monogram (e.g. "A&P") | `config.maxLength`, `config.minLength` |
| `MULTI_LINE_TEXT` | Multi-line `<textarea>` | Custom tailoring notes, Blouse measurement instructions | `config.maxLength`, `config.minLength` |
| `NUMBERS_ONLY_TEXT` | Numeric `<input type="number">` | Custom dress length in cm (e.g. `125`) | `config.minValue`, `config.maxValue` |
| `DATE` | HTML `<input type="date">` | Target wedding / event date for dispatch scheduling | `defaultValue` |
| `FILE_UPLOAD` | File picker or Cloudinary URL input | Reference embroidery pattern or custom fit photo | `config.allowedExtensions` |

## 4. Admin API Reference (Managing Modifiers)

Administrators can manage modifiers in two ways:
1. **Inline during Product Creation/Update** (via `POST /api/v1/admin/products` and `PUT /api/v1/admin/products/:id`).
2. **Granular Modifier CRUD Endpoints** (via `/api/v1/admin/products/:id/modifiers/...`).

- **Method:** `POST`
- **Route:** `/api/v1/cart/items`
- **Headers:** `Authorization: Bearer <TOKEN>` OR `x-guest-token: <UUID>`

#### Request Body Structure:
```json

  "productId": "prod-101",
  "variantId": "var-202",
  "quantity": 1,
  "modifiers": [
    {
      "modifierOptionId": "opt-halter"
    },
    {
      "modifierGroupId": "grp-embroidery",
      "textValue": "N&K"
    }
  ]
}
```

> **Backward Compatibility:** If your existing frontend code still passes an array of option IDs as `"modifierOptionIds": ["opt-halter"]`, it continues to work seamlessly!

#### Price Calculation in this Example:
- Base Variant Price (`Size XL`): `₹13,499`
- Selected Option Delta (`High Halter Neck`): `+₹450`
- Monogram: Custom text `"N&K"` (`priceDelta: 0`)
- **Computed Unit Price:** `₹13,949`
- **Cart Line Total:** `₹13,949`

## 6. Frontend Integration Examples (React / Next.js)

### 6.1. Product Detail Page (PDP) Dynamic Price Calculator

```tsx
import React, { useState, useMemo } from 'react';

interface ModifierOption {
  id: string;
  name: string;
  priceDelta: number;
  isDefault: boolean;
}

interface ModifierGroup {
  id: string;
  name: string;
  displayName: string;
  type: 'DROPDOWN' | 'RADIO_BUTTONS' | 'RECTANGLE_LIST' | 'CHECKBOX' | 'SHORT_TEXT' | 'MULTI_LINE_TEXT' | 'NUMBERS_ONLY_TEXT';
  isRequired: boolean;
  options: ModifierOption[];
  config?: {
    maxLength?: number;
    minLength?: number;
    minValue?: number;
    maxValue?: number;
    placeholder?: string;
  };
}

export function ProductCustomizer({ product }) {
  const [selectedVariantId, setSelectedVariantId] = useState(product.variants?.[0]?.id || null);
  const [selectedModifiers, setSelectedModifiers] = useState<Record<string, { optionId?: string; textValue?: string }>>({});

  // 1. Resolve Active Variant
  const activeVariant = useMemo(() => {
    return product.variants.find((v) => v.id === selectedVariantId) || null;
  }, [product, selectedVariantId]);

  // 2. Base Price (Variant overrides Product)
  const basePrice = useMemo(() => {
    if (activeVariant) {
      return Number(activeVariant.salePrice ?? activeVariant.regularPrice);
    }
    return Number(product.salePrice ?? product.regularPrice);
  }, [product, activeVariant]);

  // 3. Calculate Dynamic Modifiers Delta
  const modifiersDelta = useMemo(() => {
    let delta = 0;
    for (const group of product.modifierGroups || []) {
      const selection = selectedModifiers[group.id];
      if (selection?.optionId) {
        const opt = group.options.find((o) => o.id === selection.optionId);
        if (opt) delta += Number(opt.priceDelta || 0);
      }
    }
    return delta;
  }, [product.modifierGroups, selectedModifiers]);

  // 4. Final Live Display Price
  const currentUnitPrice = basePrice + modifiersDelta;

  const handleOptionSelect = (groupId: string, optionId: string) => {
    setSelectedModifiers((prev) => ({
      ...prev,
      [groupId]: { ...prev[groupId], optionId },
    }));
  };

  const handleTextChange = (groupId: string, textValue: string) => {
    setSelectedModifiers((prev) => ({
      ...prev,
      [groupId]: { ...prev[groupId], textValue },
    }));
  };

  const handleAddToCart = async () => {
    const payloadModifiers = Object.entries(selectedModifiers).map(([groupId, val]) => ({
      modifierGroupId: groupId,
      modifierOptionId: val.optionId || undefined,
      textValue: val.textValue || undefined,
    }));

    const res = await fetch('/api/v1/cart/items', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        productId: product.id,
        variantId: selectedVariantId,
        quantity: 1,
        modifiers: payloadModifiers,
      }),
    });
    const data = await res.json();
    if (data.success) {
      alert('Customized garment added to cart!');
    }
  };

  return (
    <div className="product-customizer">
      {/* Live Dynamic Price Header */}
      <div className="price-display">
        <span className="text-2xl font-bold">₹{currentUnitPrice.toLocaleString('en-IN')}</span>
        {modifiersDelta > 0 && (
          <span className="text-sm text-gray-500 ml-2">(Includes +₹{modifiersDelta} customizations)</span>
        )}
      </div>

      {/* Modifier Groups Rendering */}
      <div className="modifiers-container mt-6 space-y-4">
        {product.modifierGroups?.map((group: ModifierGroup) => (
          <div key={group.id} className="modifier-group">
            <label className="font-semibold block mb-1">
              {group.displayName} {group.isRequired && <span className="text-red-500">*</span>}
            </label>

            {/* Type: DROPDOWN */}
            {group.type === 'DROPDOWN' && (
              <select
                className="w-full border p-2 rounded"
                value={selectedModifiers[group.id]?.optionId || ''}
                onChange={(e) => handleOptionSelect(group.id, e.target.value)}
              >
                <option value="">-- Choose {group.displayName} --</option>
                {group.options.map((opt) => (
                  <option key={opt.id} value={opt.id}>
                    {opt.name} {opt.priceDelta > 0 ? `(+₹${opt.priceDelta})` : ''}
                  </option>
                ))}
              </select>
            )}

            {/* Type: RECTANGLE_LIST / SWATCH TILES */}
            {group.type === 'RECTANGLE_LIST' && (
              <div className="flex gap-2 flex-wrap">
                {group.options.map((opt) => {
                  const isSelected = selectedModifiers[group.id]?.optionId === opt.id;
                  return (
                    <button
                      key={opt.id}
                      type="button"
                      onClick={() => handleOptionSelect(group.id, opt.id)}
                      className={`px-4 py-2 border rounded text-sm transition-all ${
                        isSelected ? 'border-black bg-black text-white font-medium' : 'border-gray-300 hover:border-gray-500'
                      }`}
                    >
                      {opt.name}
                      {opt.priceDelta > 0 && <span className="ml-1 text-xs opacity-80">(+₹{opt.priceDelta})</span>}
                    </button>
                  );
                })}
              </div>
            )}

            {/* Type: SHORT_TEXT (Monogram Embroidery) */}
            {group.type === 'SHORT_TEXT' && (
              <input
                type="text"
                placeholder={group.config?.placeholder || 'Enter custom text...'}
                maxLength={group.config?.maxLength}
                className="w-full border p-2 rounded text-sm"
                value={selectedModifiers[group.id]?.textValue || ''}
                onChange={(e) => handleTextChange(group.id, e.target.value)}
              />
            )}
          </div>
        ))}
      </div>

      <button onClick={handleAddToCart} className="mt-8 w-full bg-emerald-700 text-white py-3 rounded font-semibold">
        Add to Bag — ₹{currentUnitPrice.toLocaleString('en-IN')}
      </button>
    </div>
  );
}
```

## 7. Error Handling & Validation Matrix

When submitting cart requests with modifiers, our API validates both options and text fields. Frontends should handle these standard error codes:

| Error Code | HTTP Status | Trigger Condition | Recommended User Feedback |
| :--- | :---: | :--- | :--- |
| `REQUIRED_MODIFIER_MISSING` | `400` | A modifier group marked `isRequired: true` was not selected or provided. | "Please select an option for [Modifier Name]." |
| `INVALID_MODIFIER` | `400` | The `modifierOptionId` or `modifierGroupId` does not belong to this product. | "Selected customization is invalid for this product." |
| `INVALID_MODIFIER_SELECTION` | `400` | Selected count is less than `minSelection` or exceeds `maxSelection`. | "Please select between [min] and [max] options." |
| `MODIFIER_TEXT_TOO_LONG` | `400` | Freeform text exceeds `config.maxLength`. | "Text cannot exceed [N] characters." |
| `MODIFIER_TEXT_TOO_SHORT` | `400` | Freeform text is shorter than `config.minLength`. | "Text must be at least [N] characters." |
| `INVALID_MODIFIER_NUMBER` | `400` | A `NUMBERS_ONLY_TEXT` field was submitted with non-numeric text. | "Please enter a valid number." |
| `MODIFIER_NUMBER_OUT_OF_RANGE` | `400` | Submitted number violates `config.minValue` or `config.maxValue`. | "Number must be between [min] and [max]." |

## 8. Summary Checklist for Frontend Engineers

1. **PDP Dynamic Pricing:** Always compute `displayedPrice = (activeVariant?.salePrice ?? product.salePrice) + sum(selectedModifiers.priceDelta)`.
2. **Distinct Line Items:** Changing the monogram text (e.g. from `"Alice"` to `"Bob"`) automatically creates two separate cart line items because our backend hashes the full configuration.
3. **Cart & Checkout Display:** Use the `selectedModifiers` array on each cart line item to render chips or subheadings (e.g., `Matching Dupatta: Heavy Zari Organza (+₹1,200)`, `Monogram: "Priya"`).
4. **Order History & Invoices:** Display the permanent `modifiers` array from `order.items[n].modifiers` to show customers their customized choices on past orders.
