## 1. Architecture & Frontend Component Mapping

The Wishlist engine follows **BigCommerce's customer-centric wishlist experience**, customized for our luxury garment catalog:
1. **Authenticated Only:** Only logged-in customers have wishlists. If a guest clicks a wishlist heart icon, the frontend should save the current URL (or product ID) and prompt the user to log in or register.
2. **Product-Level Wishlisting:** Customers save entire garments (by `productId`) without being forced to choose a size or color upfront.
3. **Variant Selection on Add-to-Cart:** When the customer adds a wishlisted garment to their cart from the wishlist screen, if the garment has sizes/colors, the frontend presents a quick-select variant picker before calling the cart API.
4. **Move vs. Add to Cart:**
   * **Add to Cart:** Adds the garment to the cart while keeping it in the wishlist.
   * **Move to Cart (`moveToCart: true`):** Adds the garment to the cart and removes it from the wishlist upon success.

### 2.1 Fast Lookup of Wishlisted Product IDs (Global Store / Initial Load)
* **Endpoint:** `GET /api/v1/wishlist/ids` (or `/api/customer/wishlist/ids`)
* **Authentication:** Required (`Authorization: Bearer <customerAccessToken>`)
* **Frontend Screen / Component:** Run on app startup, user login, or page mount in your global store (Redux, Zustand, Pinia, or Context).
* **Why Use It:** Fetches a simple array of product UUIDs (`["id1", "id2", ...]`) so the frontend can check `wishlistSet.has(product.id)` in $O(1)$ time to render filled vs. outline heart icons on all product cards without re-fetching full product objects.

#### Request
```http
GET /api/v1/wishlist/ids HTTP/1.1
Host: localhost:5000
Authorization: Bearer <accessToken>
```

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Wishlist product IDs retrieved successfully",
  "data": [
    "e8d4a1b2-11a2-4cb9-b8fe-612a4b8e3a10",
    "b2f6c9d1-55e1-4cbb-88a4-1234567890ab",
    "c1f7a0b3-8b7a-4ecb-99d6-54a86b3e1a02"
  ]
}
```

### 2.2 Toggle Product in Wishlist (Heart Button Action)
* **Endpoint:** `POST /api/v1/wishlist/toggle`
* **Authentication:** Required (`Authorization: Bearer <customerAccessToken>`)
* **Frontend Screen / Component:** Heart button on Product Cards (PLP, Category, Search, Home Carousels) and Product Details Pages (PDP).
* **Behavior:** If the product is not in the wishlist $\rightarrow$ adds it (`inWishlist: true`). If already present $\rightarrow$ removes it (`inWishlist: false`).

#### Request
```http
POST /api/v1/wishlist/toggle HTTP/1.1
Host: localhost:5000
Content-Type: application/json
Authorization: Bearer <accessToken>
```

```json
{
  "productId": "e8d4a1b2-11a2-4cb9-b8fe-612a4b8e3a10"
}
```

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `productId` | `string` | **Yes** | Valid UUID of the product to toggle |

#### Success Response (Added — `200 OK`)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Product added to wishlist",
  "data": {
    "inWishlist": true,
    "message": "Product added to wishlist",
    "productId": "e8d4a1b2-11a2-4cb9-b8fe-612a4b8e3a10"
  }
}
```

#### Success Response (Removed — `200 OK`)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Product removed from wishlist",
  "data": {
    "inWishlist": false,
    "message": "Product removed from wishlist",
    "productId": "e8d4a1b2-11a2-4cb9-b8fe-612a4b8e3a10"
  }
}
```

### 2.7 Add or Move Wishlisted Product to Cart
* **Endpoint:** `POST /api/v1/wishlist/:productId/add-to-cart`
* **Authentication:** Required (`Authorization: Bearer <customerAccessToken>`)
* **Frontend Screen / Component:** "Add to Cart" or "Move to Cart" button on Wishlist items.
* **Important Behavior:**
  * If a product has variants (sizes/colors) and no `variantId` is passed, the API returns a `400 Bad Request` with error code `VARIANT_SELECTION_REQUIRED`. The frontend must open a size/variant picker modal.
  * If `moveToCart: true` is passed, the item is removed from the customer's wishlist **only after** the cart operation succeeds.
  * If `moveToCart: false` (default), the item stays in the wishlist.

#### Request (For Product with Variant)
```http
POST /api/v1/wishlist/e8d4a1b2-11a2-4cb9-b8fe-612a4b8e3a10/add-to-cart HTTP/1.1
Host: localhost:5000
Content-Type: application/json
Authorization: Bearer <accessToken>
```

```json
{
  "variantId": "var_red_m",
  "quantity": 1,
  "moveToCart": false
}
```

| Field | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `variantId` | `string` | Conditional | `null` | Required if product has variants (`hasVariants === true`) |
| `quantity` | `number` | No | `1` | Desired purchase quantity ($1 \le \text{qty} \le 10$) |
| `moveToCart` | `boolean` | No | `false` | If `true`, removes item from wishlist after cart addition |

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "statusCode": 200,
  "message": "Item added to cart successfully",
  "data": {
    "id": "cart_abc123",
    "itemCount": 2,
    "lineItemCount": 2,
    "subtotal": 9000,
    "total": 9000,
    "items": [ ... ]
  },
```

## 4. Frontend Integration Cheatsheet (Ready-to-Use Code)

### 4.1 Global Wishlist Store Pattern (Zustand / Redux / Pinia)

```typescript
import { create } from 'zustand';
import axios from 'axios';

interface WishlistStore {
  wishlistIds: Set<string>;
  loading: boolean;
  loadWishlistIds: () => Promise<void>;
  toggleWishlist: (productId: string) => Promise<boolean>;
  isWishlisted: (productId: string) => boolean;
}

export const useWishlistStore = create<WishlistStore>((set, get) => ({
  wishlistIds: new Set<string>(),
  loading: false,

  // Call once when user logs in or app boots
  loadWishlistIds: async () => {
    try {
      set({ loading: true });
      const res = await axios.get('/api/v1/wishlist/ids');
      set({ wishlistIds: new Set(res.data.data), loading: false });
    } catch {
      set({ loading: false });
    }
  },

  // Instant optimistic toggle for heart icons on product cards & PDP
  toggleWishlist: async (productId: string) => {
    const current = new Set(get().wishlistIds);
    const wasIn = current.has(productId);

    // Optimistic UI update
    if (wasIn) current.delete(productId);
    else current.add(productId);
    set({ wishlistIds: current });

    try {
      const res = await axios.post('/api/v1/wishlist/toggle', { productId });
      return res.data.data.inWishlist;
    } catch (err) {
      // Revert if API fails
      if (wasIn) current.add(productId);
      else current.delete(productId);
      set({ wishlistIds: new Set(current) });
      throw err;
    }
  },

  isWishlisted: (productId: string) => get().wishlistIds.has(productId),
}));
```

### 4.2 Handling Guest Users Clicking Hearts
```typescript
const handleHeartClick = (product) => {
  if (!isAuthenticated) {
    // Save current route so user can be redirected back after login
    router.push(`/login?redirect=${encodeURIComponent(window.location.pathname)}`);
    return;
  }
  toggleWishlist(product.id);
};
```

### 4.3 Handling Wishlist "Add to Cart" with Variant Selection
```typescript
const handleWishlistAddToCart = async (wishlistItem, selectedVariantId = null) => {
  // If product has variants and user hasn't selected a variant yet:
  if (wishlistItem.hasVariants && !selectedVariantId) {
    // Open size/color selection modal in your UI
    openVariantPickerModal(wishlistItem);
    return;
  }

  // Call API to add to cart
  const res = await axios.post(`/api/v1/wishlist/${wishlistItem.productId}/add-to-cart`, {
    variantId: selectedVariantId,
    quantity: 1,
    moveToCart: false, // Set to true if clicking "Move to Cart"
  });

  // Update global cart store count
  updateCartCount(res.data.data.itemCount);
  toast.success('Added to cart!');
};
```

## 5. Error Code Reference Table

| HTTP Status | Error Code | Meaning | Recommended Frontend Action |
| :--- | :--- | :--- | :--- |
| `401 Unauthorized` | `UNAUTHORIZED` | Token missing or expired | Redirect user to `/login` |
| `404 Not Found` | `PRODUCT_NOT_FOUND` | Product was deleted/inactive | Show toast: *"Product is no longer available"* & refresh wishlist |
| `400 Bad Request` | `VARIANT_SELECTION_REQUIRED` | Product requires a size/color | Open size/color selector dialog |
| `400 Bad Request` | `OUT_OF_STOCK` | Product/variant has 0 stock | Display *"Out of Stock"* badge; disable add-to-cart button |
| `400 Bad Request` | `INSUFFICIENT_STOCK` | Requested qty > stock | Display warning: *"Only N items available"* |
| `404 Not Found` | `ITEM_NOT_FOUND` | Product not in user's wishlist | Item was already removed |
