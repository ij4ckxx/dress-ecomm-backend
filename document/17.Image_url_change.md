# Image Upload & URL Specification Guide (Cloudinary Integration)

**Document Reference:** `document/17.Image_url_change.md`  
**Target Audience:** Frontend Engineers (React / Next.js / Mobile) & QA / API Testers  
**Base URL:** `http://localhost:5000/api/v1` (also supports alias `/api`)  
**Storage Engine:** Cloudinary (Zero local disk storage; held in memory buffer and streamed securely)  

---

## 1. Architectural Rule: The "One Only" Mutual Exclusivity Policy

For every endpoint handling images across the platform, the client has **two valid options**:

1. **Option A — File Upload (Cloudinary):** Attach the image file (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`) via `multipart/form-data`. The backend automatically streams it directly to Cloudinary and saves the secure HTTPS URL.
2. **Option B — Direct Image URL:** Pass a valid HTTPS image URL as a string (or an array of URLs for products). The backend validates and saves the URL directly.

### ⛔ Conflict Rule:
If a request supplies **BOTH** an image file upload AND an image URL simultaneously, the backend immediately rejects the request with a `400 Bad Request` and error code `IMAGE_INPUT_CONFLICT`.

#### Standard Conflict Error Response (`400 Bad Request`):
```json
{
  "success": false,
  "message": "Conflicting image input: Please provide either an image file upload OR an image URL, not both.",
  "error": {
    "code": "IMAGE_INPUT_CONFLICT",
    "details": [
      {
        "field": "image",
        "message": "Cannot accept both an image file upload and imageUrl simultaneously. Please choose one."
      }
    ]
  }
}
```

## 3. Detailed Endpoint Specs & Postman Guide

### 3.1 Categories

#### Endpoint: `POST /api/v1/admin/categories` & `PUT /api/v1/admin/categories/:id`
* **Access:** Private (Admin with `categories:manage`)

#### Mode 1: Direct File Upload (`multipart/form-data`)
* **Headers:** `Authorization: Bearer <TOKEN>` (Do **NOT** manually set `Content-Type`; let Postman or fetch set the boundary).
* **Body (form-data):**
  * `name`: `"Haute Couture Gowns"`
  * `description`: `"Exclusive handcrafted evening gowns"`
  * `sortOrder`: `1`
  * `isFeatured`: `true`
  * `image`: `[Select File: dress.png]` *(Binary file)*
  * *(Do NOT send `imageUrl`)*

#### Mode 2: External Image URL (`application/json` or `form-data`)
* **Headers:** `Content-Type: application/json`, `Authorization: Bearer <TOKEN>`
* **Body (raw JSON):**
```json
{
  "name": "Haute Couture Gowns",
  "description": "Exclusive handcrafted evening gowns",
  "imageUrl": "https://images.unsplash.com/photo-1566174053879-31528523f8ae?auto=format",
  "sortOrder": 1,
  "isFeatured": true
}
```

### 3.2 Products

#### A. Product Creation & Update (`POST /admin/products` & `PUT /admin/products/:id`)
* **Access:** Private (Admin with `products:write`)

##### Mode 1: Direct Multiple Files Upload (`multipart/form-data`)
* **Body (form-data):**
  * `name`: `"Emerald Silk Slip Dress"`
  * `categoryId`: `"uuid-of-category"`
  * `regularPrice`: `14999.00`
  * `brand`: `"Maison De Élégance"`
  * `stockQuantity`: `25`
  * `variants`: `[{"sku":"EMR-SLK-S","size":"S","color":"Emerald","stockQuantity":10}]`
  * `images`: `[Select File 1: dress_front.jpg]`
  * `images`: `[Select File 2: dress_back.jpg]`
  * *(Do NOT send `images` as URL array)*

##### Mode 2: Array of Image URLs (`application/json`)
* **Headers:** `Content-Type: application/json`
* **Body (raw JSON):**
```json
{
  "name": "Emerald Silk Slip Dress",
  "categoryId": "2f42a77a-245c-43f1-bd1b-cce77f11bda8",
  "regularPrice": 14999.00,
  "brand": "Maison De Élégance",
  "images": [
    {
      "url": "https://res.cloudinary.com/demo/image/upload/dress_front.jpg",
      "altText": "Front View",
      "isThumbnail": true,
      "sortOrder": 0
    },
    {
      "url": "https://res.cloudinary.com/demo/image/upload/dress_back.jpg",
      "altText": "Back View",
      "isThumbnail": false,
      "sortOrder": 1
    }
  ]
}
```

## 4. Frontend Integration Examples (TypeScript & React)

### 4.1 React / Next.js Component with Toggle (Upload vs URL)

```tsx
import React, { useState } from 'react';

export const CategoryImageInput = () => {
  const [mode, setMode] = useState<'upload' | 'url'>('upload');
  const [file, setFile] = useState<File | null>(null);
  const [imageUrl, setImageUrl] = useState('');
  const [categoryName, setCategoryName] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();

    if (mode === 'upload' && file) {
      // MODE A: Send FormData with File
      const formData = new FormData();
      formData.append('name', categoryName);
      formData.append('image', file); // direct file upload

      const res = await fetch('/api/v1/admin/categories', {
        method: 'POST',
        headers: { Authorization: `Bearer ${localStorage.getItem('token')}` },
        body: formData, // Browser automatically sets multipart/form-data boundary
      });
      const data = await res.json();
      console.log('Saved via File Upload:', data);
    } else {
      // MODE B: Send JSON with Image URL
      const res = await fetch('/api/v1/admin/categories', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${localStorage.getItem('token')}`,
        },
        body: JSON.stringify({
          name: categoryName,
          imageUrl: imageUrl.trim(), // image URL
        }),
      });
      const data = await res.json();
      console.log('Saved via URL:', data);
    }
  };

  return (
    <form onSubmit={handleSubmit} className="p-4 space-y-4">
      <div>
        <label>Category Name</label>
        <input value={categoryName} onChange={(e) => setCategoryName(e.target.value)} required />
      </div>

      <div className="flex gap-4">
        <button type="button" onClick={() => { setMode('upload'); setImageUrl(''); }}>
          📁 Upload Image File
        </button>
        <button type="button" onClick={() => { setMode('url'); setFile(null); }}>
          🔗 Provide Image URL
        </button>
      </div>

      {mode === 'upload' ? (
        <div>
          <label>Choose File (Max 10MB)</label>
          <input type="file" accept="image/*" onChange={(e) => setFile(e.target.files?.[0] || null)} required />
        </div>
      ) : (
        <div>
          <label>Image URL</label>
          <input type="url" placeholder="https://..." value={imageUrl} onChange={(e) => setImageUrl(e.target.value)} required />
        </div>
      )}

      <button type="submit">Submit Category</button>
    </form>
  );
};
```

## 5. Summary of Files Changed

1. **`src/middlewares/imageExclusivity.js`** *(New)*
   * Enforces strict mutual exclusion between file uploads and URL inputs.
   * Automatically normalizes empty strings (`""`) to `undefined` so multipart form fields don't accidentally trigger validation errors.
   * Helper `parseFormDataJsonFields` parses JSON strings (e.g. `variants`, `images`, `permissions`) in `multipart/form-data`.

2. **`src/middlewares/upload.middleware.js`**
   * Configured memory storage (zero local disk persistence).
   * Upgraded max file size limit to **10MB**.
   * Flexible field names:
     * `uploadSingleImage`: accepts `image` or `file`.
     * `uploadMultipleImages`: accepts `images` or `files` (up to 10 files).
     * `uploadBannerImage`: accepts `backgroundImage`, `banner`, or `image`.
     * `uploadAvatarImage`: accepts `avatar` or `image`.

3. **`src/validators/admin/category.validator.js`** & **`src/controllers/admin/category.controller.js`** & **`src/routes/admin/category.routes.js`**
   * Preprocessing for URLs, UUIDs, and boolean FormData strings (`"true"`/`"false"`).
   * Middleware + Controller checks: rejects if both file and `imageUrl` are present.
   * Auto-uploads file to Cloudinary folder `'dresses/categories'`.

4. **`src/validators/admin/collection.validator.js`** & **`src/controllers/admin/collection.controller.js`** & **`src/routes/admin/collection.routes.js`**
   * Preprocessing for `imageUrl`, booleans, and `productIds`.
   * Rejects if both file and `imageUrl` are present.
   * Auto-uploads file to Cloudinary folder `'dresses/collections'`.

5. **`src/validators/admin/promotion.validator.js`** & **`src/controllers/admin/promotion.controller.js`** & **`src/routes/admin/promotion.routes.js`**
   * Preprocessing for `backgroundImage`, numbers, dates, and booleans.
   * Rejects if both file and `backgroundImage` URL are present.
   * Auto-uploads file to Cloudinary folder `'dresses/promotions'`.

6. **`src/validators/admin/product.validator.js`** & **`src/controllers/admin/product.controller.js`** & **`src/routes/admin/product.routes.js`**
   * Handles stringified JSON `images` and `variants` in FormData.
   * Product create/update rejects if both files and `images` URL array are supplied.
   * `POST /admin/products/:id/images` standalone gallery route rejects if both files and `url` are supplied.
   * Auto-uploads files to Cloudinary folder `'dresses/products'`.

7. **`src/validators/customer.validator.js`** & **`src/services/client/customer.service.js`** & **`src/controllers/client/customer.controller.js`** & **`src/routes/client/customer.routes.js`**
   * Added `avatarUrl` to `updateAccountDetailsSchema` and created `updateAvatarOnlySchema`.
   * Mounted `uploadAvatarImage` and `validateImageExclusivity` on `/account` (`PATCH`, `PUT`) and dedicated `/account/avatar` (`POST`).
   * Auto-uploads file to Cloudinary folder `'dresses/avatars'`.

8. **`src/validators/admin/user.validator.js`** & **`src/services/admin/user.service.js`** & **`src/controllers/admin/user.controller.js`** & **`src/routes/admin/user.routes.js`**
   * Added `avatarUrl` to admin user schemas and database update services.
   * Mounted `uploadAvatarImage` and `validateImageExclusivity` on `/admin/users` (`POST`) and `/admin/users/:id` (`PUT`).
