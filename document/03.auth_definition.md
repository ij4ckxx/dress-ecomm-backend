# AUTHENTICATION

Use a secure production-ready authentication system.

Preferred architecture:

### Access Token

Use a short-lived JWT access token.

JWT should contain only the minimum required information, for example:

```json
{
  "sub": "user-id",
  "role": "CUSTOMER"
}
```

Do NOT put these into JWT:

* Password
* Password hash
* Address
* Payment information
* Unnecessary personal information

### Refresh Token

Use a long-lived refresh token/session mechanism.

The refresh token should be securely stored and revocable.

If the project already has a session/token model, reuse it.

If a database model is genuinely required, make the minimum necessary Prisma change.

Do not modify unrelated schema/models.

Prefer storing a hash of the refresh token rather than the raw token.

---

* Return password hashes
* Return passwords
